## v0.2.1 — Native Windows portable preview / Windows 便携预览版

This is an **early Earth visualization prototype**, not a completed solar-system simulator or star atlas. A Windows portable ZIP is generated by CI using Qt's official `windeployqt` tool; the source archive is distributed in Releases as well.

**已实现 / Implemented**

- Native C++20 + Qt6 Widgets/OpenGL 3.3 desktop workspace.
- Interactive 3D Earth sphere with rotation, mouse-orbit camera, zoom and UTC time scaling.
- Approximate solar position, Earth's rotation, terminator/day-night shading and diagnostic values; **not** NASA JPL precision.
- On-demand genuine [NASA Blue Marble](https://svs.gsfc.nasa.gov/2915/) 2048×1024 global satellite mosaic (not a realtime Earth image), local caching and SHA-256/data-source provenance.
- **Actual rendered viewport screenshot export** in PNG format with matching scientific metadata, only after the NASA source texture has been loaded.
- Independent C++20 tests covering seasonal solar geometry, geographic surface normals, inertial sun vectors and day/night relationships.
- Windows portable packaging in GitHub Actions; no Python runtime needed for the user.

**未实现 / Not yet available:** Moon motion and phases, precise CSPICE solar-system ephemerides, real-star catalog rendering, deep-space navigation, exoplanet surfaces, high-resolution satellite LOD. No synthetic planetary image is presented as real observed imagery.

### Run on Windows / Windows 运行方式

1. Open [v0.2.1 Release](https://github.com/ZJY-HSBL/Celestial-Atlas/releases/tag/v0.2.1) and download `CelestialAtlas-v0.2.1-Windows-x64.zip` once the CI release has passed.
2. Extract all files and run `CelestialAtlas.exe`; do **not** run the .exe directly inside the ZIP.
3. Download the NASA imagery from the app, then drag/zoom/change UTC time and use **保存真实渲染截图** to export a genuine program screenshot.
4. Requires Windows x64, an OpenGL 3.3 capable GPU/driver and [Microsoft Visual C++ x64 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). If running without an OpenGL 3.3 context, rendering will fail.

See the [portable guide](docs/WINDOWS-PORTABLE.md) for details.

### Scientific provenance / 科学数据来源

NASA Blue Marble is a **multi-date satellite observation composite**, not a live Earth image. Image downloads are dimension checked and SHA-256 recorded along with source details. Displayed sunlight is derived from an explicitly **low-precision** solar calculation, with simplifications in Earth orientation and atmospheric lighting.

**No fake planets / 禁止伪造天体影像。** Unknown exoplanet surfaces remain unknown. NASA, ESA, PDS, Hubble and other third-party images retain their specific data-credit and license conditions.

### Build from source / 源码构建

Requires CMake 3.21+, C++20, Qt 6.4+ (Core, Gui, Widgets, Network, OpenGL, OpenGLWidgets).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Linux scientific core only, without Qt:

```bash
cmake -S . -B build-core -DCMAKE_BUILD_TYPE=Release -DATLAS_BUILD_GUI=OFF
cmake --build build-core --parallel
ctest --test-dir build-core --output-on-failure
```

Optional Python utility for downloading the original satellite mosaic (not needed at runtime):

```bash
python scripts/fetch_nasa_earth.py
```
