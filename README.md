## v0.4.1 — NASA LRO Moon Globe / 真实月球全球观测影像

v0.4.1 fixes Moon-specific interface inconsistencies detected in the v0.4.0 actual render: header, active scene navigation, lunar radius, global-map loaded status, and hiding Earth-only sunlight controls in Moon view.

v0.4 introduces a **switchable 3D Moon Survey globe** with a genuine NASA Lunar Reconnaissance Orbiter global image mosaic, its own download/cache/attribution and genuine program-rendered screenshots.

This remains an **early Earth visualization prototype**, not a completed solar-system simulator or star atlas. The new precision astronomy module links the unmodified official NASA NAIF CSPICE toolkit when enabled and uses JPL DE442s ephemeris kernels. The Windows default executable remains CSPICE-disabled until its compiler-compatible toolkit build is validated. A Windows portable ZIP is generated by CI using Qt's official `windeployqt` tool; the source archive is distributed in Releases as well.

**已实现 / Implemented**

- Native C++20 + Qt6 Widgets/OpenGL 3.3 desktop workspace.
- **Earth / Moon view switching** in the same viewport. The Moon uses the NASA SVS CGI Moon Kit (2025 processed LROC WAC global map, 2048×1024).
- Separate Earth/Moon on-demand NASA image downloads with SHA-256 source provenance and dimensional validation.
- Interactive 3D Earth sphere with rotation, mouse-orbit camera, zoom and UTC time scaling.
- Approximate solar position, Earth's rotation, terminator/day-night shading and diagnostic values; **not** NASA JPL precision.
- On-demand genuine [NASA Blue Marble](https://svs.gsfc.nasa.gov/2915/) 2048×1024 global satellite mosaic (not a realtime Earth image), local caching and SHA-256/data-source provenance.
- **Actual OpenGL viewport and full desktop screenshot export** in PNG format with matching scientific metadata, only after the NASA source texture has been loaded.
- NASA JPL DE442s Earth-relative Sun/Moon geometric J2000 vectors via optional official CSPICE adapter, with scientifically computed Moon illuminated fraction, phase angle and Earth–Moon distance.
- Missing toolkit/kernel support clearly indicated in the UI; no fabricated Moon positions or phases.
- Link to an authentic NASA LRO Moon observation mosaic (not falsely used as a measured 3D lunar texture).
- Independent C++20 tests covering solar geometry, geographic surface normals, Moon illumination edge cases, and official-kernel eclipse epoch integration in Linux CI.
- Windows portable packaging in GitHub Actions; no Python runtime needed for the user.

**未实现 / Not yet available:** 3D Moon orbital animation, precise Earth rotation/lighting via IERS frames, Windows CSPICE binaries, real-star catalog rendering, deep-space navigation, exoplanet surfaces, high-resolution satellite LOD. **CSPICE Sun/Moon numerical ephemerides and Moon illuminated fraction are supported on Linux only when compiled with NAIF and verified kernels.** No synthetic planetary image is presented as real observed imagery.

### Run on Windows / Windows 运行方式

1. Open [v0.4.1 Release](https://github.com/ZJY-HSBL/Celestial-Atlas/releases/tag/v0.4.1) and download `CelestialAtlas-v0.4.1-Windows-x64.zip` once the CI release has passed.
2. Extract all files and run `CelestialAtlas.exe`; do **not** run the .exe directly inside the ZIP.
3. Download the NASA imagery from the app, then drag/zoom/change UTC time and use **保存真实渲染截图** to export a genuine program screenshot.
4. Requires Windows x64, an OpenGL 3.3 capable GPU/driver and [Microsoft Visual C++ x64 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). If running without an OpenGL 3.3 context, rendering will fail.

See the [portable guide](docs/WINDOWS-PORTABLE.md) for details.

### Scientific provenance / 科学数据来源

NASA Blue Marble is a **multi-date satellite observation composite**, not a live Earth image. Image downloads are dimension checked and SHA-256 recorded along with source details. Displayed sunlight is derived from an explicitly **low-precision** solar calculation, with simplifications in Earth orientation and atmospheric lighting.

**No fake planets / 禁止伪造天体影像。** Unknown exoplanet surfaces remain unknown. NASA, ESA, PDS, Hubble and other third-party images retain their specific data-credit and license conditions.

### Build from source / 源码构建

Requires CMake 3.21+, C++20, Qt 6.4+ (Core, Gui, Widgets, Network, OpenGL, OpenGLWidgets).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Linux scientific core only, without Qt:

```bash
cmake -S . -B build-core -DCMAKE_BUILD_TYPE=Release -DATLAS_BUILD_GUI=OFF
cmake --build build-core --parallel
ctest --test-dir build-core --output-on-failure
```

Optional Python utility for downloading the original satellite mosaic (not needed at runtime):

```bash
python scripts/fetch_nasa_earth.py
```

### Precision science / NASA JPL 精密星历

[Full official CSPICE integration instructions](docs/SPICE-INTEGRATION.md). On Linux, install NASA NAIF CSPICE N0067 and download `de442s.bsp` and `naif0012.tls` with `python scripts/fetch_spice_kernels.py` (developer tool only). Build with `-DATLAS_ENABLE_CSPICE=ON -DCSPICE_ROOT=/path/to/cspice`. Run with `ATLAS_SPICE_KERNEL_DIR=/path/to/kernels`.

The **Moon illuminated fraction** is computed using real geocentric vectors from DE442s, *not* a procedural animation. The **Earth terminator is still the previous approximate solar model**, not high-precision SPICE orientation. CSPICE/toolkit and kernels are external resources with NASA NAIF rules, not included in the repository.
