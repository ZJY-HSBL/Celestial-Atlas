## v0.7.0 — Precision Earth–Moon on Windows / Windows 原生 CSPICE

**New in v0.7.0:** The Windows x64 CI now builds with the **official NASA NAIF CSPICE N0067 Visual C 64-bit toolkit**, tests JPL DE442s and lunar DE440 PCK/FK numerical queries, and bundles the four unmodified JPL kernels with source provenance alongside the portable executable. The Windows executable must pass `--spice-self-test` directly from the release folder before the release pipeline can finish.

### Shared Earth–Moon System / 同一空间里的真实地月系统

The Earth and Moon are now drawn in **one Earth-centered J2000 3D world** rather than two separate viewing modes. The Moon’s translation comes from the actual **JPL DE442s** Earth→Moon vector. Its attitude uses a **DE440 Moon_ME binary PCK / FK** frame rotation. Both use real NASA observation-derived textures.

### Features / 当前功能

- **Three modes:** Earth Observatory, Moon Survey, shared Earth–Moon System.
- **Real 3D lunar position:** same J2000 coordinates as Sun and Earth, with shared UTC time controls.
- **Body-fixed attitude:** CSPICE `pxform_c("MOON_ME","J2000",et,...)`, matrix mapped into the same OpenGL axes as the translation.
- **Scientific scale:** real Earth–Moon center separation (roughly 60 Earth radii), and a clearly labeled presentation mode dividing **only the Moon-center translation by 12**. Earth/Moon sphere radii retain their correct ratio (6371 km / 1737.4 km).
- **Camera controls:** overview, focus Earth, focus Moon; zoom and orbit with mouse.
- **Observed NASA imagery:** [Earth Blue Marble](https://svs.gsfc.nasa.gov/2915/) and [LRO Moon CGI Kit](https://svs.gsfc.nasa.gov/4720/), downloaded separately, checked and cached with SHA-256 and metadata.
- **Science tests:** real Windows and Linux JPL SPK/PCK/FK integration, eclipse-date lunar-phase geometry, deployed Windows EXE kernel self-test, two-date Moon movement, true/compressed separation invariants, actual Linux Moon/earth OpenGL rendering, and release hashes.

### Windows download / Windows 便携版

[Download v0.7.0 Windows x64 preview](https://github.com/ZJY-HSBL/Celestial-Atlas/releases/tag/v0.7.0) (Qt libraries packaged with `windeployqt`). Unzip fully, install the Microsoft Visual C++ x64 Redistributable if necessary, and use an OpenGL 3.3-capable GPU/driver.

**Windows precision calculation:** This version enables CSPICE in the Windows build and ships the corresponding unmodified official NASA/JPL kernel resources in the `kernels/` subdirectory. The executable loads those files automatically, or uses an explicit `ATLAS_SPICE_KERNEL_DIR` override. **Do not delete `kernels/` from the extracted folder.** You can run `CelestialAtlas.exe --spice-self-test` to verify real ephemerides and lunar-frame calculations. No Python installation is required to run the desktop software. The Windows GUI's actual GPU rendering must still be verified on a user's computer; CI verifies real CSPICE numerics and packaging, while Linux Mesa validates rendered pixels.

### Build / 构建

```bash
cmake -S . -B build-core -DATLAS_BUILD_GUI=OFF
cmake --build build-core --parallel
ctest --test-dir build-core --output-on-failure
```

For official NAIF C toolkit N0067 and JPL LSK/SPK/PCK/FK kernels, read [docs/SPICE-INTEGRATION.md](docs/SPICE-INTEGRATION.md). Python is used only to prepare optional image/ephemeris resources.

### Scientific boundaries / 科学边界

- Lunar positions are geometric geocentric J2000, without light-time/stellar aberration or local observer parallax.
- **Earth orientation is still an approximate GMST model**, not a rigorously UT1/ITRF/EOP-calibrated orientation, even when the Moon and Sun vectors use true JPL positions.
- Spherical mean-radius shapes do not include measured Moon relief or lunar shadowing/eclipses. Surface imagery is observation-derived **processed global mosaics**, not real-time photographs.
- Compressed distance is **not a physical-scale model** and is always visibly labeled. No invented Moon positions are used if kernels are missing.
- No Gaia sky, solar-system-wide free flight, topocentric astronomy, DEM terrain, or precision eclipses yet.
